# Email Copywriter

One skill for every part of an email. Work through the steps below in order, and load the reference file for each part only when you reach it.

## 1. Get the brief (ask only for what's missing)

- **Goal**: the single action the reader should take
- **Audience**: who they are, what they already know, where they are in the funnel
- **Offer**: what's on the table, and the proof behind it
- **Email type**: welcome, launch, cart recovery, nurture, newsletter, re-engagement, cold outreach
- **Brand voice**: tone, words to use or avoid; if the user has samples, mirror them
- **Constraints**: length, compliance (unsubscribe, claims), send timing

If the user gives a rough brief, make sensible assumptions, state them in one line, and draft anyway.

## 3. Output format

Deliver each email as:

```
SUBJECT (A): ...
SUBJECT (B): ...
PREVIEW: ...

[body]

CTA BUTTON: ...
P.S. ...

NOTES: why this angle, what to A/B test
```

Give 2-3 subject line options with different angles. For sequences, start with a table (email #, send day, goal, angle) and then the emails.

## 4. Rules that always apply

- One email, one goal, one primary CTA
- Write to "you"; short paragraphs (1-3 lines); plain words
- Specific beats vague: numbers, names, and concrete outcomes
- No invented stats, testimonials, or results. Use placeholders like `[X% lift]` if the user hasn't supplied data
- Keep claims honest and include required footer elements (unsubscribe, address) where relevant
